# ATLAS

Segundo cérebro corporativo para decisões, reuniões, treinamentos, conhecimento e ações.

## Stack
Next.js, TypeScript, Supabase (PostgreSQL/Auth/RLS), OpenAI opcional, interface responsiva.

## Início
1. `npm install`
2. Configure `.env.local` conforme `.env.example`
3. Execute `supabase/schema.sql` no projeto Supabase
4. `npm run dev`

Sem credenciais o produto mostra instruções de configuração, sem simular autenticação ou persistência.

**Atenção:** não armazenar dados pessoais ou segredos neste repositório público. Configure segurança, backups, SMTP, domínio e observabilidade antes da operação real.
